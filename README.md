## ✨ Features & Capabilities

- 🛡️ **Advanced Fingerprint Protection**: Spoofs Canvas, WebGL Vendor/Renderer, AudioContext, ClientRects, WebRTC IP leakage, Screen Resolution, CPU cores, and RAM.
- 🔒 **Isolated Profile Sandboxes**: Each browser instance operates with its own separate cookies, local storage, cache, and proxy configuration.
- 🌐 **Proxy & Tunneling**: Direct integration with HTTP, HTTPS, SOCKS5, and residential proxies with live IP location diagnostics.
- ⚡ **Auto-Update with Permission**: Automatically checks for new versions on launch. Always asks for your explicit permission before downloading or applying updates.
- 🤖 **Automation Tools**: Built-in human-like warmup bots, social media auto-posting suites, and multi-profile workflows.

## 📖 Quick Start Guide

### Option 1: Setup Installer
1. Download **`Amplify_Setup_1.0.0.exe`** from the link above.
2. Run the installer and follow the setup wizard.
3. Launch **Amplify** from your Desktop shortcut or Start Menu.

### Option 2: Portable Edition
1. Download **`Amplify_Portable_v1.0.0.zip`**.
2. Extract the zip to any folder of your choice (e.g. `C:\Amplify` or a USB drive).
3. Open the folder and double-click **`Amplify.exe`** to start immediately.
